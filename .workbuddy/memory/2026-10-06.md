# 2026-10-06

## Image Zoomer 扩展 MV2 → MV3 迁移

- `manifest.json`：manifest_version 3；`background.page` + `persistent` → `background.service_worker: js/background.js`；
  `*://*/*` 从 `permissions` 移到 `host_permissions`；版本 1.1.0 → 1.2.0；新增 `minimum_chrome_version: 88`；删除 `background.html`。
- `js/background.js` 改为 Service Worker 入口，顶部 `importScripts("app_bg.js")`（SW 无 DOM）：
  - 三处 `XMLHttpRequest` → `fetch`（defaults.jsn / sieve.jsn / sieve 解析请求）。
  - `document.baseURI` → `chrome.runtime.getURL()`；去掉 `document.title`、`Components/Ci.nsIPrivateBrowsingChannel`。
  - `responseXML.baseURI` 无法在 SW 使用，改用文本正则解析 `<base href>`。
  - `window.saveURI` → 全局变量 `saveURI`。
  - 全部 Promise 化；新增 `ensureReady()`：SW 空闲被终止后重新唤醒时自动重载配置（prefs_ 不再常驻）。
  - `Port.listen` 包装器始终返回 true 以支持异步 sendResponse；无需响应的命令显式 `postMessage()` 关闭通道。
  - `Tabs.create` / `saveURI` 加 `.catch` 防止 unhandled rejection。
- `js/app_bg.js`：`cfg` 用显式 Promise 包装 chrome.storage（不依赖 API promise 化）并校验 `runtime.lastError`；
  移除 localStorage 迁移（SW 无 localStorage）；`Port.parse_msg` 补充 `tab` / `isPrivate`（sender.tab.incognito）。
- `includes/content.js`：`chrome.extension.inIncognitoContext`（MV3 废弃）→ IIFE 顶部 `isIncognito` 兼容降级检测。
- 验证：node --check 全量语法通过；另写 `/tmp/mv3_smoke.js` 用 vm + mock chrome API 跑通
  SW 启动 → sieve 载入(300 条规则) → hello / open / download / cfg_get / savePrefs / resolve 全链路。
- 注意：`RegExp.escape` 已有原生实现时不再覆盖。
